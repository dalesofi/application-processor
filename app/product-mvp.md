# Product MVP

## Goal

Build a small personal AI assistant that helps Sofia decide which jobs are worth applying to and prepares the right application materials.

## MVP input

A job description pasted into the application.

## MVP output

- APPLY / STRETCH / SKIP
- Reasoning
- Best CV
- Strongest matching evidence
- Gaps
- Risks
- Application angle

## MVP constraints

- No automatic applications
- No job scraping
- No browser automation
- Human reviews the recommendation
- Evidence-based decisions

## Future

1. Job URL ingestion
2. Application writing
3. Application tracking
4. Interview preparation
5. Job discovery
6. Outcome learning
7. Optional application automation
